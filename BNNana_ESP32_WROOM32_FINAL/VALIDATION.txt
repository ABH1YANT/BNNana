Important:
The first draft of this ESP32 code had a packed-weight bit indexing issue for
32/64/128/160-bit rows. That issue is fixed in this version. Do not use the
older BNNana_ESP32_WROOM32.zip; use the v2 archive.

Preprocessing status:
The inference engine expects 16 uint8 Q1.8 values. The uploaded export metadata
specifies q1_8_value = uint8_value / 256.0 and range 0..255.
The raw network-flow -> 16 preprocessed features -> Q1.8 conversion is NOT
implemented here because the actual LUT CSV contents used during dataset
preprocessing were not part of the uploaded current export.


PREPROCESSING
==============
16 supplied feature LUT CSVs were incorporated.
LUT normalized_value was quantized as round(value*256), clipped to 0..255.
Upper-bit addressing follows lut_metadata.json discarded_lower_bits.
ACK Flag Count uses exact-value addressing.
